# 📦 Supply Chain Analysis Dashboard | Power BI & SQL

## 📌 Project Overview

This project analyzes supply chain operations using **Power BI, SQL, and Excel**.

The dashboard provides insights into **revenue, inventory, product performance, manufacturing, shipping, lead time, defect rates, and supplier performance** to support data-driven decision-making.

---

## 🎯 Project Objectives

- Analyze overall supply chain performance
- Monitor revenue, units sold, orders, and stock
- Analyze product and inventory performance
- Evaluate supplier performance
- Compare supplier cost, lead time, and defect rate
- Analyze manufacturing and shipping operations
- Identify key operational insights

---

## 🛠️ Tools & Technologies

- **Power BI** – Dashboard and visualization
- **SQL / MySQL** – Data cleaning and validation
- **Excel** – Data handling
- **Power Query** – Data transformation
- **DAX** – KPI calculations and analysis
